# ZotLit Reader

The ZotLit Reader plugin. It shares the vocabulary of the Obsidian Plugin context (`apps/obsidian/GLOSSARY.md`) and adds these terms.

**ZotLit Reader**:
The Obsidian plugin with id `zotlit-reader` that opens vault PDFs in the ZotLit PDF Reader. It works alone, without ZotLit and without Zotero.
_Avoid_: reader plugin, PDF plugin

**PDF takeover**:
The state in which ZotLit Reader, not Obsidian's built-in PDF view, opens each PDF of the vault: in a tab, in an embed, in a hover preview and in a canvas card. ZotLit Reader turns it on at start-up.
_Avoid_: override, hijack
