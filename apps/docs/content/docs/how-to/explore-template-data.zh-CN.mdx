searchTitle: "查找用于 Obsidian 模板的 Zotero 字段"
description: "打开模板数据浏览器查找 Zotero 字段（例如期刊名称），并将其复制为可粘贴到模板中的代码片段。"
---

import { Accordion, Accordions } from "fumadocs-ui/components/accordion";
import { Card, Cards } from "fumadocs-ui/components/card";
import { Steps, Step } from "fumadocs-ui/components/steps";
import { Command } from "@/components/command";
import { UiLabel } from "@/components/ui-label";
import { m } from "@/paraglide/messages.js";

打开一篇文献笔记，运行 <Command inline name={m.command_open_template_data_explorer_name()} />，搜索所需字段并复制。本页以将期刊名称复制为 `{{ zt.publicationTitle }}` 为例。

模板通过同一个变量名 `zt` 读取文献的全部信息：`zt.title` 为标题，`zt.authors` 为作者。在此处浏览不会修改任何模板，也不会变动 Zotero 文库中的任何内容。复制的内容为纯文本。若要在编辑时直接将字段插入配置方案，请改用编辑器中的 <UiLabel name={m.workbench_view_fields()} />，详见[自定义模板](/docs/how-to/customize-a-template#insert-field)。

<Steps>
  <Step>
    ### 打开浏览器 [#open-explorer]

    打开一篇文献笔记。打开命令面板并运行 <Command inline name={m.command_open_template_data_explorer_name()} />。

    ![命令面板筛选至 ZotLit：打开模板数据浏览器，该命令以红框标出](/img/how-to/explore-template-data-1-open-explorer.webp)

    浏览器将在右侧边栏的标注下方打开，并在顶部显示文献名称。

  </Step>
  <Step>
    ### 查看字段列表 [#find-panel]

    查看标题为 <UiLabel name={m.workbench_fields_heading()} /> 的面板。文献的各个字段归在不同的分组标题下。第一个分组是 <UiLabel name={m.workbench_explorer_section_common()} />，包含 Title、Authors、Date、Abstract、Published in 和 Citation key。每一行都显示字段名称及其在当前文献中的具体值。

    ![右侧边栏中以红框标出的模板字段面板，列出 Ten Simple Rules for Better Figures 的常用字段](/img/how-to/explore-template-data-2-find-panel.webp)

    若要查看其他文献，点击面板头部的 <UiLabel name={m.workbench_choose_item()} />，在 <UiLabel name={m.workbench_recently_updated()} /> 下选择一篇，使用 <UiLabel name={m.workbench_search_zotero()} /> 搜索，或选择一个内置示例。

  </Step>
  <Step>
    ### 搜索字段 [#search]

    在 <UiLabel name={m.workbench_fields_search_note()} /> 框中输入字段的部分名称，例如 `published`。

    ![输入了 published 并以红框标出的搜索框，下方显示一行匹配结果 Published in](/img/how-to/explore-template-data-3-search-field.webp)

    列表将仅显示匹配的行。这里显示 **Published in**，对应的值为 **PLOS Computational Biology**。

  </Step>
  <Step>
    ### 复制代码片段 [#copy]

    右键点击 **Published in** 所在行，或点击其 <UiLabel name={m.workbench_explorer_row_actions()} /> 按钮，然后选择 <UiLabel name={m.workbench_explorer_menu_copy_output()} />。

    ![Published in 所在行展开的菜单，其中“复制输出”以红框标出](/img/how-to/explore-template-data-4-copy-output.webp)

    菜单中提供了 <UiLabel name={m.workbench_explorer_menu_copy_path()} />、<UiLabel name={m.workbench_explorer_menu_copy_value()} />、<UiLabel name={m.workbench_explorer_menu_copy_output()} /> 以及 <UiLabel name={m.workbench_explorer_menu_copy_if_present()} />。

  </Step>
  <Step>
    ### 确认复制成功 [#copied]

    查看窗口右上角。

    ![窗口右上角以红框标出的“已复制”提示](/img/how-to/explore-template-data-5-copied.webp)

    屏幕上会出现 <UiLabel name={m.workbench_field_copy_done()} /> 提示，剪贴板中已存有 `{{ zt.publicationTitle }}`。将其粘贴到配置方案的笔记文本中，详见[自定义模板](/docs/how-to/customize-a-template)。

  </Step>
</Steps>

<Accordions multiple>
<Accordion title="如果显示内容不一致" id="fixes">

- **显示的是文献列表而非字段** —— 运行命令时没有处于活动状态的文献笔记。从列表中选择一篇文献，或打开一篇文献笔记后重新运行命令。
- <UiLabel name={m.workbench_fields_no_matches()} /> ——
  缩短或清空搜索框中的文本。
- <UiLabel name={m.workbench_field_copy_failed()} /> ——
  选中文本框中显示的代码片段内容并手动复制。
- **代码片段操作位于 Liquid 和 Eta 两个子菜单中** —— 选择你的模板所使用的语言。如果是全新开始，请选择 Liquid。
- **Zotero 每次打开 Obsidian 时都弹出确认提示** —— 请参考[关闭 Zotero 安全提示](/docs/how-to/suppress-zotero-security-prompt)。
- **字段值看起来不是最新的** —— 数据会自动更新，但你也可以从面板菜单中选择 <UiLabel name={m.workbench_refresh_item()} /> 立即刷新。
- **模板渲染结果有误且你想提交反馈** —— 请参考收集调试日志中的[模板数据](/docs/how-to/collect-debug-logs#template-data)。

</Accordion>
<Accordion title="选择哪种复制操作" id="copy-actions">

| 菜单项                                                         | 复制内容                                               |
| -------------------------------------------------------------- | ------------------------------------------------------ |
| <UiLabel name={m.workbench_explorer_menu_copy_output()} />     | 字段值，例如 `{{ zt.title }}`                          |
| <UiLabel name={m.workbench_explorer_menu_copy_if_present()} /> | 带有条件判断的代码块，仅当文献包含该字段时才输出字段值 |
| <UiLabel name={m.workbench_explorer_menu_copy_loop()} />       | 列表中的每一项独占一行 Markdown 列表（仅限列表）       |
| <UiLabel name={m.workbench_explorer_menu_copy_joined()} />     | 列表中的所有项合并在一行，以逗号分隔（仅限列表）       |
| <UiLabel name={m.workbench_explorer_menu_copy_path()} />       | 仅复制路径，例如 `zt.creators[0].family`               |
| <UiLabel name={m.workbench_explorer_menu_copy_value()} />      | 当前文献的实际值；列表和对象将以 JSON 格式复制         |

若在设置中启用了 <UiLabel name={m.settings_template_js_enable_name()} />，代码片段操作将出现在“Liquid”和“Eta”两个子菜单中；请选择模板所使用的语言。若未启用该选项，Liquid 操作项将直接显示在菜单中。

</Accordion>
<Accordion title="其他打开方式" id="other-ways-to-open">

| 位置                                                                                  | 选择的操作                                                                               |
| ------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 文献笔记的文件菜单（在文件列表或标签页上右键点击）                                    | <UiLabel name={m.template_data_explorer_menu_explore()} />。将打开该笔记对应文献的字段。 |
| 标注侧边栏中某条标注的“更多选项”菜单                                                  | <UiLabel name={m.template_data_explorer_menu_explore()} />。将打开该标注的字段。         |
| Zotero 中右键点击某个条目，子菜单 <UiLabel name={m["zotero.menu_submenu.label"]()} /> | <UiLabel name={m["zotero.menu_item_explore.label"]()} />。需要安装 ZotLit Companion。    |
| Zotero 的 PDF 阅读器中右键点击某个标注                                                | <UiLabel name={m["zotero.menu_reader_annot_explore"]()} />。需要安装 ZotLit Companion。  |

</Accordion>
<Accordion title="复制 Zotero 标识符" id="indexed-key">

Zotero 标识符用于唯一标识某个条目、附件、标注或笔记。当工具询问需要处理哪个条目时，可以复制该标识符：

- 在 Obsidian 中，当前打开的文献笔记：运行 <Command inline name={m.command_copy_item_key_name()} />，或从文件菜单中选择该项。文献笔记的 `zotero-key` 属性中也记录了此标识符。
- 在标注行上：打开更多选项菜单并选择 <UiLabel name={m.indexed_key_menu_copy_annotation()} />。
- 在浏览器的面板菜单中：选择 <UiLabel name={m.command_copy_item_key_name()} /> 或 <UiLabel name={m.indexed_key_menu_copy_annotation()} />。
- 在 Zotero 中（需要 ZotLit Companion）：右键点击条目并选择 <UiLabel name={m["zotero.menu_submenu.label"]()} /> > <UiLabel name={m["zotero.menu_item_copy_key.label"]({ count: 1, kind: "item" })} /> 或 <UiLabel name={m["zotero.menu_item_copy_key.label"]({ count: 1, kind: "attachment" })} />（选中多行时将按每行一个标识符进行复制）。在 PDF 阅读器中，右键点击标注并选择 <UiLabel name={m["zotero.menu_reader_annot_copy_key"]()} />。

</Accordion>
<Accordion title="单个高亮的字段" id="annotation-fields">

标注模板读取的字段属于单个高亮标注，而非整篇文献。选择 <UiLabel name={m.workbench_choose_annotation()} /> 可从文献的标注或六种内置示例（高亮、下划线、笔记、文本、图片、手绘）中进行选择。或者，在 `zt.annotations` 下打开某行的更多选项菜单，选择 <UiLabel name={m.workbench_explorer_menu_explore_annotation()} />。此时会显示名为 <UiLabel name={m.template_data_explorer_note_root()} /> 的面包屑导航；点击其返回按钮（<UiLabel name={m.template_data_explorer_back_to_note_root()} />）即可返回文献字段列表。

</Accordion>
</Accordions>
