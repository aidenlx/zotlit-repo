import { Accordion, Accordions } from "fumadocs-ui/components/accordion";
import { Card, Cards } from "fumadocs-ui/components/card";
import { Steps, Step } from "fumadocs-ui/components/steps";
import { Command } from "@/components/command";
import { UiLabel } from "@/components/ui-label";
import { m } from "@/paraglide/messages.js";

打开 <UiLabel name={m.workbench_tab_properties()} /> 标签页，选择 <UiLabel name={m.workbench_properties_add()} />，并将属性关联到 Zotero 字段。然后运行 <Command inline name={m.command_update_note_metadata_name()} /> 将其同步到已有笔记中。

属性是笔记顶部的区块，在 Obsidian 中显示为 **Properties** 列表。每个配置方案都保留自己的规则，修改会自动保存。ZotLit 预装了四个属性：`title`、`related`、`collections` 和 `citekey`。

开始之前，请按照[自定义模板](/docs/how-to/customize-a-template#open-profile)打开默认配置方案并选择一篇论文。本页使用来自[探索模板数据](/docs/how-to/explore-template-data)的期刊名称 `zt.publicationTitle`。

<Steps>
  <Step>
    ### 打开属性标签页 [#open-properties]

    在配置方案编辑器中，选择 <UiLabel name={m.workbench_tab_properties()} />。

    ![配置方案编辑器的“属性”标签页，红框标出，title、related、collections 和 citekey 各占一行](/img/how-to/configure-frontmatter-properties-1-properties-tab.webp)

    列表中每一行显示一个属性及其对应论文的值。<UiLabel name={m.workbench_result_heading()} /> 会显示相同的属性。

  </Step>
  <Step>
    ### 添加属性 [#add-property]

    选择列表下方的 <UiLabel name={m.workbench_properties_add()} />。

    ![属性列表下方的“添加属性”按钮，用红框标出](/img/how-to/configure-frontmatter-properties-2-add-property.webp)

    底部会打开一个新行，包含 <UiLabel name={m.workbench_properties_name()} />、<UiLabel name={m.workbench_properties_expression()} /> 和 <UiLabel name={m.workbench_properties_merge()} />。

  </Step>
  <Step>
    ### 命名属性 [#name]

    在 <UiLabel name={m.workbench_properties_name()} /> 中输入 `journal`。

    ![新行的“属性名称”字段已输入 journal，用红框标出](/img/how-to/configure-frontmatter-properties-3-name.webp)

    该行的标题变为 **journal**。该名称是 ZotLit 写入笔记顶部的键名。

  </Step>
  <Step>
    ### 选择属性值 [#value]

    将 <UiLabel name={m.workbench_properties_expression()} /> 保持为 <UiLabel name={m.workbench_properties_format_value()} />。在其下方的输入框中，将 `zt.title` 替换为 `zt.publicationTitle`。输入时会弹出一个字段列表；按 Escape 键可将其关闭。

    ![journal 行的值输入框包含 zt.publicationTitle，用红框标出](/img/how-to/configure-frontmatter-properties-4-value.webp)

    该行现在显示论文的期刊 **PLOS Computational Biology**。属性值的其他选项还有 <UiLabel name={m.workbench_properties_format_text()} /> 和 <UiLabel name={m.workbench_properties_format_rule()} />。

  </Step>
  <Step>
    ### 选择更新时的行为 [#merge]

    在 <UiLabel name={m.workbench_properties_merge()} /> 下，保持为 <UiLabel name={m.workbench_properties_merge_replace()} />。

    ![“笔记更新时”选项设置为“替换现有值”，用红框标出](/img/how-to/configure-frontmatter-properties-5-merge.webp)

    这样，每次笔记更新时 ZotLit 都会覆盖该属性。<UiLabel name={m.workbench_properties_merge_append()} /> 会追加新项并保留笔记中已有的项。<UiLabel name={m.workbench_properties_merge_keep()} /> 仅在属性为空时写入。详见[合并策略](/docs/reference/templates/frontmatter#merge-strategies)。

  </Step>
  <Step>
    ### 检查预览 [#check-preview]

    查看 <UiLabel name={m.workbench_result_heading()} /> 中的 **Properties** 列表。

    ![笔记预览，其中新行 journal 显示 PLOS Computational Biology，用红框标出](/img/how-to/configure-frontmatter-properties-6-preview.webp)

    预览中显示了 **journal** 这一行及其值 **PLOS Computational Biology**。

  </Step>
  <Step>
    ### 更新已有笔记 [#apply]

    ZotLit 创建新笔记时会自动添加该属性。已经存在的笔记只有在更新时才会改变。打开笔记，打开命令面板，然后运行 <Command inline name={m.command_update_note_metadata_name()} />。

    ![命令面板中“ZotLit: 更新文献笔记元数据”用红框标出](/img/how-to/configure-frontmatter-properties-7-update-command.webp)

    该笔记的 **Properties** 列表中新增了 **journal** 及其值 **PLOS Computational Biology**。

    ![文献笔记的 Properties 列表，journal 和 tags 所在行用红框标出](/img/how-to/configure-frontmatter-properties-8-note-properties.webp)

  </Step>
</Steps>

## 将 Zotero 标签添加到笔记中 [#zotero-tags]

再添加一个属性，将论文在 Zotero 中的标签保留在笔记的 `tags` 属性中。使用以下值重复步骤 2 和 3，然后更新笔记。

| 输入项                                                 | 值                                                                                  |
| ------------------------------------------------------ | ----------------------------------------------------------------------------------- |
| <UiLabel name={m.workbench_properties_name()} />       | `tags`                                                                              |
| <UiLabel name={m.workbench_properties_expression()} /> | <UiLabel name={m.workbench_properties_format_value()} />, `zt.tags \| obsidian_tag` |
| <UiLabel name={m.workbench_properties_merge()} />      | <UiLabel name={m.workbench_properties_merge_replace()} />                           |

![tags 属性行，zt.tags 通过管道传递给 obsidian_tag，用红框标出](/img/how-to/configure-frontmatter-properties-9-tags.webp)

若想保留在 Obsidian 中手动添加的标签，请改选 <UiLabel name={m.workbench_properties_merge_append()} />。`obsidian_tag` 过滤器会将空格和其他字符转换为 Obsidian 标签允许的形式。例如，名为 `Methodology` 和 `Open Access` 的 Zotero 标签会变为：

```yaml
tags:
  - Methodology
  - Open_Access
```

所有规则请参阅 [`obsidian_tag` 过滤器参考](/docs/reference/templates/syntax#obsidian-tag)。

<Accordions multiple>
<Accordion title="如果显示不符合预期" id="fixes">

- **某行标记为** <UiLabel name={m.workbench_properties_row_problem()} /> → 表达式无法使用。<UiLabel name={m.workbench_problems_heading()} /> 区域会说明具体问题并提供 <UiLabel name={m.workbench_problems_where_entry()} /> 以打开该行。详见[验证](/docs/reference/templates/frontmatter#validation)和[以 Markdown 形式编辑配置方案](/docs/how-to/edit-a-profile-as-markdown#problems)。
- **用 JavaScript 编写的属性没有任何效果** → 当该设备上的 <UiLabel name={m.settings_template_js_enable_name()} /> 处于关闭状态时，它将处于非活动状态，ZotLit 会报告受影响的字段：<UiLabel name={m.notice_frontmatter_js_inert({ fields: "…" })} /> 详见[启用 JavaScript 模板](/docs/how-to/enable-javascript-templates)。

</Accordion>
<Accordion title="编辑、移除或重新排列属性" id="edit-or-reorder">

选择属性行即可编辑。使用 <UiLabel name={m.workbench_properties_remove()} /> 即可将其移除。

各行的顺序决定了 ZotLit 创建新笔记时键的顺序。拖动行首的拖动手柄（<UiLabel name={m.workbench_drag_to_reorder()} />），或选中手柄并按 `Alt+Arrow Up` 或 `Alt+Arrow Down`。

重新排序不会改变已有笔记：笔记中已存在的键会保留原位置。如需重新排列单篇笔记的属性，请在 Obsidian 的属性面板中拖动属性类型图标。该笔记需要包含两个或更多属性。

</Accordion>
<Accordion title="通过 Agent 设置属性" id="agent">

配备 [ZotLit 模板 skill](/docs/install-skill) 的 Agent 可以使用表达式 `zt.tags | obsidian_tag` 添加托管的 `tags` 属性。[模板工作台 CLI](/docs/reference/template-workbench-cli) 允许其配置该属性并测试渲染结果。

</Accordion>
</Accordions>
