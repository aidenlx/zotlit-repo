ZotLit Reader is a separate Obsidian plugin that reads the PDFs in your vault. Install it through BRAT. With ZotLit beside it, your PDFs also show your Zotero annotations and the tools to make new ones.

You need Obsidian 1.15.1 or later on a desktop computer; ZotLit Reader is desktop only. You do not need ZotLit or Zotero just to read PDFs.

<Callout type="info">
  ZotLit Reader is in development. It is not yet in Obsidian's community plugin
  directory. Its only release so far, `1.0.0-beta.0`, tests the release process.
</Callout>

## Install ZotLit Reader [#install]

BRAT (Beta Reviewers Auto-update Tester) is an Obsidian plugin that installs and updates plugins from GitHub.

<Steps>
  <Step>
    ### Install BRAT [#install-brat]

    Open BRAT in the Obsidian plugin directory, then select **Install** and **Enable**. Skip this step if BRAT is already installed.

    <ActionLink href="obsidian://show-plugin?id=obsidian42-brat" kind="obsidian">Install BRAT</ActionLink>

    BRAT appears in **Settings > Community plugins**.

  </Step>
  <Step>
    ### Add ZotLit Reader to BRAT [#add-to-brat]

    Select the link below. Or open the command palette, run **BRAT: Add a beta plugin**, and enter `aidenlx/zotlit-reader`.

    <ActionLink href="obsidian://brat?plugin=aidenlx/zotlit-reader" kind="obsidian">Add ZotLit Reader to BRAT</ActionLink>

    BRAT installs the plugin.

  </Step>
  <Step>
    ### Turn on ZotLit Reader [#turn-on]

    Go to **Settings > Community plugins** and turn on **ZotLit Reader**. If it does not appear, refresh the plugin list.

    Open a PDF from the file explorer. It opens in ZotLit Reader, with <UiLabel name={m.pdf_reader_zoom_out()} /> and <UiLabel name={m.pdf_reader_zoom_in()} /> in the toolbar at the top. <UiLabel name={m.reader_settings_open_all_pdfs_name()} /> is on after install, so every PDF opens there.

  </Step>
</Steps>

BRAT updates ZotLit Reader when a new release comes out. If PDFs still open in Obsidian's PDF view, turn on <SettingsPath plugin="ZotLit Reader" page={m.reader_settings_page()} setting={m.reader_settings_open_all_pdfs_name()} />.

## What ZotLit adds [#with-zotlit]

ZotLit Reader works alone, with no ZotLit and no Zotero. When ZotLit is also installed and turned on, the two plugins connect by themselves, in either start order.

| Feature                                                                 | ZotLit Reader alone | With ZotLit |
| :---------------------------------------------------------------------- | :------------------ | :---------- |
| [Read](#navigate) and [find text](#find)                                | Yes                 | Yes         |
| [Copy text and selection links](#copy)                                  | Yes                 | Yes         |
| [PDF embeds, hover previews, canvas cards](#open-all-pdfs)              | Yes                 | Yes         |
| [Dark mode](#theme)                                                     | Yes                 | Yes         |
| Zotero annotations on the page                                          | No                  | Yes         |
| [Make and change Zotero annotations](/docs/how-to/edit-pdf-annotations) | No                  | Yes         |
| Annotation view in the sidebar                                          | No                  | Yes         |

Annotation links that ZotLit writes into notes open in ZotLit Reader with the annotation selected.

## ZotLit without ZotLit Reader [#without-reader]

ZotLit opens PDFs in Obsidian's own PDF view when ZotLit Reader is not installed or is turned off. It does the same when the two versions do not work together. A link that names a page, such as an annotation link, opens that view at its page. The page shows no Zotero annotations and no annotation tools.

The first time this happens, a notice stays on screen until you close it. Its title is <UiLabel name={m.notice_reader_fallback()} /> Below it are one sentence and one button:

| Situation                         | Sentence                                                                        | Button                                                       |
| :-------------------------------- | :------------------------------------------------------------------------------ | :----------------------------------------------------------- |
| ZotLit Reader is not installed    | <UiLabel name={m.settings_reader_status_install()} />                           | <UiLabel name={m.settings_reader_status_install_action()} /> |
| ZotLit Reader is turned off       | <UiLabel name={m.settings_reader_status_turn_on()} />                           | <UiLabel name={m.settings_reader_status_turn_on_action()} /> |
| The versions do not work together | <UiLabel name={m.settings_reader_status_update({ plugin: "ZotLit Reader" })} /> | <UiLabel name={m.settings_reader_status_update_action()} />  |

When ZotLit is the older plugin, the last sentence names ZotLit instead. ZotLit shows each notice once per vault on this computer, so a second PDF opens without one.

To install ZotLit Reader, follow the [BRAT steps](#install) above. To turn it on, go to **Settings > Community plugins**. To update either plugin, update it through BRAT or the community directory, wherever you installed it from.

### See the connection [#status]

The same sentence and button sit in the <UiLabel name={m.settings_reader_status_name()} /> row at the top of <SettingsPath page={m.settings_page_reader()} />. The row adds <UiLabel name={m.settings_reader_status_fallback()} /> When the two plugins are connected, it reads <UiLabel name={m.settings_reader_status_connected()} /> and has no button.

The setup steps at the top of the [Library View](/docs/how-to/use-library-view) end with a <UiLabel name={m.welcome_step_reader_title()} /> step. It shows <UiLabel name={m.welcome_step_reader_recommended()} /> until the plugins connect, then <UiLabel name={m.welcome_step_reader_connected()} />.

If the row still says <UiLabel name={m.settings_reader_status_install_action()} /> after you installed ZotLit Reader, close the settings and open them again.

## Move through the paper [#navigate]

The toolbar at the top of the reader holds the page controls.

- Type a page number in the page box and press `Enter`. When the PDF prints its own page numbers, such as `iv` or `213`, the box shows them.
- Select <UiLabel name={m.pdf_reader_zoom_out()} /> or <UiLabel name={m.pdf_reader_zoom_in()} />. You can also hold `Ctrl` (Windows) or `Command` (macOS) and scroll, or pinch on a trackpad.
- Select <UiLabel name={m.pdf_reader_display_options()} /> to choose <UiLabel name={m.pdf_reader_fit_width()} />, <UiLabel name={m.pdf_reader_fit_height()} />, <UiLabel name={m.pdf_reader_single_page()} />, <UiLabel name={m.pdf_reader_two_page_odd()} />, or <UiLabel name={m.pdf_reader_two_page_even()} />.

In <UiLabel name={m.pdf_reader_fit_width()} /> or <UiLabel name={m.pdf_reader_fit_height()} />, the left and right arrow keys turn the page.

To turn off the printed page numbers, clear <UiLabel name={m.pdf_reader_show_page_labels()} /> in the same menu. The menu shows this item only for a PDF that has printed page numbers.

### Use the sidebar [#sidebar]

Select <UiLabel name={m.pdf_reader_toggle_sidebar()} /> to show the page thumbnails. Select <UiLabel name={m.pdf_reader_sidebar_options()} /> to switch between <UiLabel name={m.pdf_reader_thumbnails()} /> and <UiLabel name={m.pdf_reader_outline()} />.

Select a thumbnail or a heading to go there. To find the heading of the page you are reading, select <UiLabel name={m.pdf_reader_sidebar_options()} />, then <UiLabel name={m.pdf_reader_reveal_in_outline()} />. Drag the sidebar's edge to change its width.

The reader remembers the page and the two-page layout of each PDF, and the sidebar you used last.

## Find text [#find]

1. With the reader in focus, press `Ctrl+F` (Windows) or `Command+F` (macOS).
2. Type in the <UiLabel name={m.pdf_reader_find_placeholder()} /> box. The count shows how many matches the paper has.
3. Press `Enter` or `F3` for the next match. Press `Shift+Enter` or `Shift+F3` for the previous one. `Ctrl+G` and `Ctrl+Shift+G` (`Command` on macOS) work too.

Select <UiLabel name={m.pdf_reader_find_options()} /> to turn on <UiLabel name={m.pdf_reader_match_case()} />, <UiLabel name={m.pdf_reader_highlight_all()} />, <UiLabel name={m.pdf_reader_match_diacritics()} />, or <UiLabel name={m.pdf_reader_whole_words()} />. The reader keeps your choices for the next search. Press `Escape` to close the search.

## Copy text and links [#copy]

Select text on the page, then right-click it.

- <UiLabel name={m.pdf_reader_copy()} /> copies the text alone.
- <UiLabel name={m.pdf_reader_copy_as_quote()} /> copies the text as a quote,
  with a link back to the passage.
- <UiLabel name={m.pdf_reader_copy_selection_link()} /> copies a link that opens
  the PDF with the passage highlighted.
- On macOS, the menu also offers to look up the selected text.

Right-click a thumbnail to copy a link to its page. Right-click a heading in the table of contents to copy a link to that section.

A link that you copy here works in Obsidian's own PDF viewer too. Some pages have text that the two readers read differently. There, the reader copies a link to the page instead, and the menu has no <UiLabel name={m.pdf_reader_copy_selection_link()} />.

## Read in dark mode [#theme]

Open <UiLabel name={m.pdf_reader_display_options()} /> and select <UiLabel name={m.pdf_reader_adapt_to_theme()} />. With a dark Obsidian theme, the pages turn dark and the text turns light. Drawn shapes keep their hue, so dark blue turns light blue. Photos and other pictures stay as they are.

## Open every PDF in ZotLit Reader [#open-all-pdfs]

After install, ZotLit Reader opens every PDF of your vault. These use ZotLit Reader:

- PDFs that you open from the file explorer, a search, or a link.
- PDF embeds in your notes, such as `![[paper.pdf#page=3]]`.
- Hover previews of PDF links.
- PDF cards on a canvas.

To give these PDFs back to Obsidian's own PDF viewer, turn off <SettingsPath plugin="ZotLit Reader" page={m.reader_settings_page()} setting={m.reader_settings_open_all_pdfs_name()} />. They also go back when you turn ZotLit Reader off. The PDFs that ZotLit opens still use ZotLit Reader while the setting is off.

An embed has a <UiLabel name={m.pdf_reader_embed_more_options()} /> button. Select <UiLabel name={m.pdf_reader_embed_open()} /> to read the whole PDF. The same menu has Obsidian's own link items, such as **Open in new tab**.

## Limits [#limits]

- Obsidian's own PDF viewer shows no ZotLit annotation tools. A link that ZotLit wrote into a note, such as an annotation link, still opens in ZotLit Reader. This is true while <UiLabel name={m.reader_settings_open_all_pdfs_name()} /> is off too.
- A link made with **Copy link to selection** in Obsidian's own viewer opens with the passage highlighted. When the two readers read that page's text differently, the link opens on its page without the highlight.
- A PDF card on a canvas has no **Save current position in document** button.
- In Live Preview, a PDF embed has no **Edit this block** button. To change the embed's link, switch the note to Source mode.
- If ZotLit Reader shows <UiLabel name={m.reader_takeover_unavailable()} />, your Obsidian version does not let it open all PDFs. ZotLit still opens its own PDFs in ZotLit Reader.
