import { Accordion, Accordions } from "fumadocs-ui/components/accordion";
import { Card, Cards } from "fumadocs-ui/components/card";
import { Steps, Step } from "fumadocs-ui/components/steps";
import { Command } from "@/components/command";
import { LessonLink } from "@/components/lesson-link";
import { SettingsPath } from "@/components/settings-path";
import { UiLabel } from "@/components/ui-label";
import { m } from "@/paraglide/messages.js";

在修改模板前，若想先创建一篇文献笔记，请从 <LessonLink slug="connect-zotero-to-obsidian" /> 开始。

打开默认配置方案，在笔记正文中插入 Zotero 字段，并在实时的 <UiLabel name={m.workbench_result_heading()} /> 中查看效果。所做修改会自动保存并应用到新笔记。此处的操作不会改动你的 Zotero 文库。

你所编辑的是一个**配置方案**：模板文件夹（默认为 `templates`）中的一个文件，对于默认配置方案即为 `zotlit-profile.default.md`。参见[模板工作原理](/docs/reference/templates/how-templates-work)。

<Steps>
  <Step>
    ### 打开配置方案 [#open-profile]

    在 Obsidian 中，打开 <SettingsPath page={m.settings_page_profiles()} />。在 <UiLabel name={m.settings_profile_default_name()} /> 所在行，选择铅笔按钮 <UiLabel name={m.settings_profile_edit()} />。

    ![文献笔记配置方案设置页面，默认方案所在行的铅笔按钮用红框标出](/img/how-to/customize-a-template-1-open-profile.webp)

    模板工作台将作为新标签页打开，名称为 **Default · Profile**，左侧为笔记文本，右侧为 <UiLabel name={m.workbench_result_heading()} />。首次打开时，ZotLit 会在模板文件夹中创建 `zotlit-profile.default.md`。

  </Step>
  <Step>
    ### 选择文献进行预览 [#choose-paper]

    选择标签页上方的 <UiLabel name={m.workbench_choose_item()} />，然后在 <UiLabel name={m.workbench_recently_updated()} /> 下选择一篇文献，或使用 <UiLabel name={m.workbench_search_zotero()} /> 进行搜索。

    ![编辑器上方打开的选择条目列表，Rougier 等人 (2014) 的《Ten Simple Rules for Better Figures》所在行用红框标出](/img/how-to/customize-a-template-2-choose-paper.webp)

    标签页上方的一行会显示该文献的名称，且 <UiLabel name={m.workbench_result_heading()} /> 会填充该文献的属性、链接和标注。

  </Step>
  <Step>
    ### 打开 Note 标签页 [#tabs]

    选择 <UiLabel name={m.workbench_tab_note()} />。每个标签页负责编辑配置方案的一部分：<UiLabel name={m.workbench_tab_note()} /> 对应笔记正文，<UiLabel name={m.workbench_tab_properties()} /> 在[配置 Frontmatter 属性](/docs/how-to/configure-frontmatter-properties)中介绍，而 <UiLabel name={m.workbench_tab_name_and_folder()} /> 与 <UiLabel name={m.workbench_tab_match()} /> 则在[为不同笔记使用不同模板](/docs/how-to/use-different-templates)中介绍。

    ![配置方案编辑器的 Note 标签页，标签页行用红框标出，左侧为笔记文本，右侧为笔记预览](/img/how-to/customize-a-template-3-note-tab.webp)

    编辑器中显示笔记文本：包含标题的标题行、链接行以及 **Annotations** 小节。旁边的预览展示了该文献渲染后的完整笔记。

  </Step>
  <Step>
    ### 插入 Zotero 字段 [#insert-field]

    在笔记文本中，将光标置于要插入值的位置，例如 `Published in: ` 之后。在标头中选择 <UiLabel name={m.workbench_view_fields()} />，选择 **Published in** 所在行，并在弹出的卡片上选择 <UiLabel name={m.workbench_fields_insert()} />。

    ![右侧边缘展开的字段列表，Published in 字段的卡片显示其模板路径，插入按钮用红框标出](/img/how-to/customize-a-template-4-insert-field.webp)

    光标处会出现 `{{ zt.publicationTitle }}`，列表随即关闭。ZotLit 在生成笔记时会将双花括号中的每个字段替换为该文献自身的值。如果想在打开编辑器之前查找字段，请参阅[探索模板数据](/docs/how-to/explore-template-data)。

  </Step>
  <Step>
    ### 查看预览 [#check-preview]

    查看 <UiLabel name={m.workbench_result_heading()} />。

    ![笔记预览，新增的 Published in: PLOS Computational Biology 一行用红框标出](/img/how-to/customize-a-template-5-preview.webp)

    笔记中现在会显示 **Published in: PLOS Computational Biology**。预览会随着输入实时更新，且支持 Obsidian 的撤销与重做。

  </Step>
  <Step>
    ### 更新已有笔记 [#apply]

    新笔记会立即使用你编辑后的配置方案。已经存在的笔记会保留原有文本，直到你对其进行更新。打开该笔记，打开命令面板，并运行 <Command inline name={m.command_update_note_name()} />。

    ![已打开文献笔记上方的命令面板，ZotLit: Update literature note 命令用红框标出](/img/how-to/customize-a-template-6-update-note.webp)

    此时会弹出提示 <UiLabel name={m.notice_updated_note()} />。<Command inline name={m.command_overwrite_note_name()} /> 则会在确认后替换整个笔记正文。

  </Step>
</Steps>

<Accordions multiple>
<Accordion title="如果显示与预期不符" id="fixes">

- **首次创建文件时报错** → 选择错误提示旁的重试操作。
- **预览为空或未显示文献** → 选择 <UiLabel name={m.workbench_choose_item()} />，从文库中选择一篇文献或选择内置示例。
- **预览失败** → 重试预览，或使用 <UiLabel name={m.workbench_choose_item()} /> 选取另一篇文献。你可以继续编辑。
- **字段列表提示“Select a place in the template to insert a field.”** → 在笔记文本中选择一个位置，然后重新打开 <UiLabel name={m.workbench_view_fields()} />。
- **修改正文后笔记未发生变化** → 运行 <Command inline name={m.command_update_note_name()} /> 刷新属性。如果配置方案中没有托管块，ZotLit 会显示 <UiLabel name={m.notice_updated_note_no_managed_block()} />。正文修改会自动应用于新笔记；若要重建现有笔记的正文，请运行 <Command inline name={m.command_overwrite_note_name()} />。
- **Eta 模板没有反应** → Eta 模板需要启用 <UiLabel name={m.settings_template_js_enable_name()} /> 设置。如果未启用，Eta 模板将保持非活动状态，且不会回退到内置文本。参见[启用 JavaScript 模板](/docs/how-to/enable-javascript-templates)。
- **片段调用处标记为** <UiLabel name={m.workbench_partial_missing()} /> → 片段已被重命名或删除。请在模板调用处修改片段名称，或重新创建该片段文件。
- **片段字段输出为空** → Liquid 调用中缺少数据参数；请写为 `{% render "name" with zt as zt %}`。

</Accordion>
<Accordion title="编辑已有笔记对应的配置方案" id="existing-note">

打开该文献笔记并运行命令 <Command inline name={m.template_workbench_open_layout()} />，或在该笔记的文件菜单中选择 <UiLabel name={m.template_workbench_open_layout()} />。模板工作台视图将打开，并已预先选中该笔记对应的文献。

</Accordion>
<Accordion title="修改插入引文的文本" id="citation-text">

- 打开 <SettingsPath page={m.settings_page_citations()} />。在 <UiLabel name={m.settings_citation_text_name()} /> 所在行，选择铅笔按钮，提示为 <UiLabel name={m.settings_citation_text_open()} />（或运行命令 <Command inline name={m.command_customize_citation_text_name()} />）。
  文件 `zotlit-citation.md` 将在 <UiLabel name={m.workbench_tab_citation()} /> 标签页中打开。（如果你之前从未自定义过该文件，该行将显示 <UiLabel name={m.settings_template_using_default()} />，ZotLit 会先根据内置文本创建该文件。）
- <UiLabel name={m.workbench_citation_result_heading()} />
  显示引文的最终效果。在窗格菜单中，选择
  <UiLabel name={m.template_workbench_preview_main_citation()} /> 或
  <UiLabel name={m.template_workbench_preview_alt_citation()} />
  测试这两种类型，或选择 <UiLabel name={m.template_workbench_use_example()} />
  加载内置引文格式。
- 一个模板同时控制主要引文和替代引文；[`zt.variant`](/docs/reference/templates/data#citation-variant) 标识当前请求的是哪一种。参见[引文模板读取的字段](/docs/reference/templates/data#citation-templates)。
- 笔记中已有的引文为纯文本，将保持原样。所做的编辑将应用到下一次插入的引文中。
- 如需放弃修改，请在 <UiLabel name={m.settings_citation_text_name()} /> 所在行选择旋转箭头按钮，提示为 <UiLabel name={m.settings_template_reset()} />。确认 <UiLabel name={m.settings_citation_text_reset_confirm_title()} /> 即可将该文件移至 Obsidian 的回收站。

</Accordion>
<Accordion title="在多个配置方案之间复用文本" id="share-a-partial">

- **片段**（partial）是一个可复用的模板文件（`zotlit-partial.<name>.md`），任何配置方案或引文模板都可以按名称调用它。
- 如需创建片段，请打开 <SettingsPath page={m.settings_page_profiles()} setting={m.settings_partials_heading()} /> 并选择 <UiLabel name={m.settings_partial_add()} />。或者，在工作台编辑器中选中文本，右键点击并选择 <UiLabel name={m.template_workbench_extract_partial()} />。
- 在 Liquid 中使用 `{% render "authors" with zt as zt %}` 调用片段（输入 `{% render "` 会列出你的片段并自动补全参数）。在 Eta 中，使用 `<%~ include("authors", zt) %>` 调用。
- 有关命名和参数的详细信息，请参阅[调用片段](/docs/reference/templates/syntax#calling-a-partial)。

</Accordion>
<Accordion title="恢复内置模板" id="restore-built-in">

在 <SettingsPath /> 中的 <UiLabel name={m.settings_profile_document_name()} /> 所在行，选择 <UiLabel name={m.settings_profile_document_restore()} />。确认 <UiLabel name={m.settings_profile_document_restore_title()} />。ZotLit 会将你的配置方案文件移至 Obsidian 的回收站，需要时可以从中恢复。现有笔记将保留其当前内容，直至更新。

</Accordion>
</Accordions>
