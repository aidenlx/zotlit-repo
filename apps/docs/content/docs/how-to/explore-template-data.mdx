Open a literature note, run <Command inline name={m.command_open_template_data_explorer_name()} />, search for the field you need, and copy it. This page copies the journal name as `{{ zt.publicationTitle }}`.

A template reads everything about a paper from one name, `zt`: `zt.title` is the title and `zt.authors` the authors. Browsing here changes no template and touches nothing in your Zotero library. What you copy is plain text. To insert a field straight into a profile while you edit it, use <UiLabel name={m.workbench_view_fields()} /> in the editor instead, as in [Customize a template](/docs/how-to/customize-a-template#insert-field).

<Steps>
  <Step>
    ### Open the explorer [#open-explorer]

    Open a literature note. Open the command palette and run <Command inline name={m.command_open_template_data_explorer_name()} />.

    ![The command palette filtered to ZotLit: Open template data explorer, with the command outlined in red](/img/how-to/explore-template-data-1-open-explorer.webp)

    The explorer opens in the right sidebar, below the annotations, and names your paper at the top.

  </Step>
  <Step>
    ### Read the field list [#find-panel]

    Look at the panel titled <UiLabel name={m.workbench_fields_heading()} />. The paper's fields sit under section headings. The first section is <UiLabel name={m.workbench_explorer_section_common()} />, with Title, Authors, Date, Abstract, Published in, and Citation key. Each row shows the field's name and your paper's own value.

    ![The Template fields panel in the right sidebar, outlined in red, listing the common fields of Ten Simple Rules for Better Figures](/img/how-to/explore-template-data-2-find-panel.webp)

    To look at another paper, select <UiLabel name={m.workbench_choose_item()} /> in the panel header and pick one under <UiLabel name={m.workbench_recently_updated()} />, search with <UiLabel name={m.workbench_search_zotero()} />, or choose a built-in example.

  </Step>
  <Step>
    ### Search for the field [#search]

    Type part of the field's name, such as `published`, in the <UiLabel name={m.workbench_fields_search_note()} /> box.

    ![The search box with published typed in and outlined in red, and one matching row, Published in, below it](/img/how-to/explore-template-data-3-search-field.webp)

    The list shows only the matching rows. Here it shows **Published in** with the value **PLOS Computational Biology**.

  </Step>
  <Step>
    ### Copy the snippet [#copy]

    Right-click the row **Published in**, or select its <UiLabel name={m.workbench_explorer_row_actions()} /> button, and select <UiLabel name={m.workbench_explorer_menu_copy_output()} />.

    ![The menu open on the Published in row, with Copy output outlined in red](/img/how-to/explore-template-data-4-copy-output.webp)

    The menu offers <UiLabel name={m.workbench_explorer_menu_copy_path()} />, <UiLabel name={m.workbench_explorer_menu_copy_value()} />, <UiLabel name={m.workbench_explorer_menu_copy_output()} />, and <UiLabel name={m.workbench_explorer_menu_copy_if_present()} />.

  </Step>
  <Step>
    ### Check that it copied [#copied]

    Look at the top right of the window.

    ![The notice Copied outlined in red at the top right of the window](/img/how-to/explore-template-data-5-copied.webp)

    The notice <UiLabel name={m.workbench_field_copy_done()} /> appears, and your clipboard holds `{{ zt.publicationTitle }}`. Paste it into the note text of a profile, as in [Customize a template](/docs/how-to/customize-a-template).

  </Step>
</Steps>

<Accordions multiple>
<Accordion title="If something looks different" id="fixes">

- **A list of papers instead of fields** — no literature note was active when you ran the command. Pick a paper from the list, or open a literature note and run the command again.
- <UiLabel name={m.workbench_fields_no_matches()} /> — shorten or clear the text
  in the search box.
- <UiLabel name={m.workbench_field_copy_failed()} /> — select the snippet text
  displayed on screen and copy it manually.
- **The snippet items are in two submenus, Liquid and Eta** — choose the language your template uses. If you are starting fresh, choose Liquid.
- **Zotero asks for confirmation each time it opens Obsidian** — follow [Suppress the Zotero security prompt](/docs/how-to/suppress-zotero-security-prompt).
- **The values look out of date** — data updates automatically, but you can select <UiLabel name={m.workbench_refresh_item()} /> from the pane menu to refresh it immediately.
- **A template rendered the wrong thing and you want to report it** — follow [Template data](/docs/how-to/collect-debug-logs#template-data) in Collect debug logs.

</Accordion>
<Accordion title="Which copy action to choose" id="copy-actions">

| Menu item                                                      | What it copies                                                     |
| -------------------------------------------------------------- | ------------------------------------------------------------------ |
| <UiLabel name={m.workbench_explorer_menu_copy_output()} />     | The value, e.g. `{{ zt.title }}`                                   |
| <UiLabel name={m.workbench_explorer_menu_copy_if_present()} /> | The value inside a block that writes it only when the paper has it |
| <UiLabel name={m.workbench_explorer_menu_copy_loop()} />       | Each item of a list on its own Markdown list line (lists only)     |
| <UiLabel name={m.workbench_explorer_menu_copy_joined()} />     | Every item of a list on one line, separated by commas (lists only) |
| <UiLabel name={m.workbench_explorer_menu_copy_path()} />       | The path alone, e.g. `zt.creators[0].family`                       |
| <UiLabel name={m.workbench_explorer_menu_copy_value()} />      | This paper's value; lists and objects copy as JSON                 |

With <UiLabel name={m.settings_template_js_enable_name()} /> enabled in settings, snippet actions appear inside two submenus, "Liquid" and "Eta"; pick the language your template uses. With it off, the Liquid items sit in the menu directly.

</Accordion>
<Accordion title="Other ways to open it" id="other-ways-to-open">

| Where                                                                                     | What to select                                                                          |
| ----------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| A literature note's file menu (right-click in the file explorer or the tab)               | <UiLabel name={m.template_data_explorer_menu_explore()} />. Opens on that note's paper. |
| An annotation's more-options menu in the annotation sidebar                               | <UiLabel name={m.template_data_explorer_menu_explore()} />. Opens on that annotation.   |
| Zotero, right-click one item, submenu <UiLabel name={m["zotero.menu_submenu.label"]()} /> | <UiLabel name={m["zotero.menu_item_explore.label"]()} />. Needs ZotLit Companion.       |
| Zotero's PDF reader, right-click an annotation                                            | <UiLabel name={m["zotero.menu_reader_annot_explore"]()} />. Needs ZotLit Companion.     |

</Accordion>
<Accordion title="Copy a Zotero key" id="indexed-key">

A Zotero key identifies one item, attachment, annotation, or note. Copy one when a tool asks which item to work on:

- In Obsidian, on the active literature note: run <Command inline name={m.command_copy_item_key_name()} />, or select it from the file menu. A literature note also records this in its `zotero-key` property.
- On an annotation row: open the more-options menu and select <UiLabel name={m.indexed_key_menu_copy_annotation()} />.
- In the explorer's pane menu: select <UiLabel name={m.command_copy_item_key_name()} /> or <UiLabel name={m.indexed_key_menu_copy_annotation()} />.
- In Zotero (with ZotLit Companion): right-click rows and select <UiLabel name={m["zotero.menu_submenu.label"]()} /> > <UiLabel name={m["zotero.menu_item_copy_key.label"]({ count: 1, kind: "item" })} /> or <UiLabel name={m["zotero.menu_item_copy_key.label"]({ count: 1, kind: "attachment" })} /> (selecting several rows copies one key per line). In the PDF reader, right-click an annotation and select <UiLabel name={m["zotero.menu_reader_annot_copy_key"]()} />.

</Accordion>
<Accordion title="Fields of one highlight" id="annotation-fields">

The fields an annotation template reads belong to an individual highlight rather than the paper. Select <UiLabel name={m.workbench_choose_annotation()} /> to choose from the paper's annotations or six built-in examples (highlight, underline, note, text, image, ink). Alternatively, under `zt.annotations`, open a row's more-options menu and select <UiLabel name={m.workbench_explorer_menu_explore_annotation()} />. A breadcrumb labelled <UiLabel name={m.template_data_explorer_note_root()} /> appears; click its back button (<UiLabel name={m.template_data_explorer_back_to_note_root()} />) to return to the paper's fields.

</Accordion>
</Accordions>
