import { Steps, Step } from "fumadocs-ui/components/steps";
import { Card, Cards } from "fumadocs-ui/components/card";
import { Command } from "@/components/command";
import { SettingsPath } from "@/components/settings-path";
import { UiLabel } from "@/components/ui-label";
import { m } from "@/paraglide/messages.js";

为该文献类型添加一个配置方案，在其 <UiLabel name={m.workbench_tab_match()} /> 标签页中设置条件，ZotLit 便会为每个匹配的条目自动选用它。本页将为书籍创建一个配置方案。

配置方案决定文献笔记的名称、文件夹、属性与正文。新建的配置方案初始为默认配置方案（Default）的副本。在开始之前，请先按照[自定义模板](/docs/how-to/customize-a-template)编辑一次默认配置方案。

<Steps>
  <Step>
    ### 添加配置方案 [#add-profile]

    在 Obsidian 中，打开 <SettingsPath page={m.settings_page_profiles()} />。在 <UiLabel name={m.settings_profile_other_heading()} /> 列表的顶部标题中，选择 <UiLabel name={m.settings_profile_add()} />。

    ![文献笔记配置方案设置页面，其他配置方案列表标题中的添加配置方案按钮用红框标出](/img/how-to/use-different-templates-1-add-profile.webp)

    随后会打开 <UiLabel name={m.settings_profile_add()} /> 对话框。

  </Step>
  <Step>
    ### 命名并选择其文件夹 [#name-folder]

    在 <UiLabel name={m.settings_profile_name_name()} /> 中输入 `Books`。在 <UiLabel name={m.settings_profile_folder_name()} /> 中输入 `literatures/books`，然后选择 <UiLabel name={m.settings_profile_add()} />。文件夹是可选的，留空则使用默认配置方案的文件夹。

    ![添加配置方案对话框，名称 Books 和文件夹 literatures/books 用红框标出](/img/how-to/use-different-templates-2-name-folder.webp)

    该配置方案会在编辑器中打开，标题显示为 **Books · Profile**。ZotLit 会将 `zotlit-profile.books.md` 写入你的模板文件夹。你输入的名称是列表中看到的标签。配置方案的唯一标识是文件内部的 ID，因此重命名文件不会产生任何影响。参阅[配置方案](/docs/reference/templates/how-templates-work#profiles)。

  </Step>
  <Step>
    ### 编辑笔记正文与其属性 [#edit]

    编辑器会打开在 <UiLabel name={m.workbench_tab_name_and_folder()} /> 标签页。<UiLabel name={m.settings_profile_folder_name()} /> 显示为 `literatures/books`。按照[自定义模板](/docs/how-to/customize-a-template#insert-field)与[配置 Frontmatter 属性](/docs/how-to/configure-frontmatter-properties)中的方法编辑 <UiLabel name={m.workbench_tab_note()} /> 和 <UiLabel name={m.workbench_tab_properties()} />。

    ![Books 配置方案的“名称与文件夹”标签页，其中设为 literatures/books 的“文献笔记文件夹”字段用红框标出](/img/how-to/use-different-templates-3-folder.webp)

    只有使用该配置方案创建的笔记才会应用这些设置。

  </Step>
  <Step>
    ### 设置选用它的条件 [#match]

    选择 <UiLabel name={m.workbench_tab_match()} />。该标签页初始包含一行空白条件。选择 <UiLabel name={m.workbench_filter_field_item_type()} />，中间的选项保持为 **is**，并选择 **Book**。

    ![匹配标签页，其中“Item type is Book”这一条件用红框标出](/img/how-to/use-different-templates-4-match.webp)

    该行显示为 **Item type is Book**。未填写值的条件行不会匹配任何条目。在条件上方，选择它们的组合方式：<UiLabel name={m.workbench_match_match_all()} />、<UiLabel name={m.workbench_match_match_any()} /> 或 <UiLabel name={m.workbench_match_match_none()} />。这些条件与[查询视图](/docs/how-to/use-query-files#filter)的筛选条件相同。参阅[配置方案匹配](/docs/reference/templates/profile-match)。

  </Step>
  <Step>
    ### 针对条目检查匹配条件 [#check]

    点击条件下方的 <UiLabel name={m.workbench_choose_match_item()} /> 并选择一本书。

    ![选择书籍后的匹配标签页，其中“匹配所选条目”结果用红框标出](/img/how-to/use-different-templates-5-check.webp)

    该标签页会显示 <UiLabel name={m.workbench_match_result_yes()} />。对于其他任何条目类型，它会显示 <UiLabel name={m.workbench_match_result_no()} />。在设置页面中，该配置方案所在的行会显示 <UiLabel name={m.settings_profile_match_status({ state: "evaluable" })} />。

  </Step>
  <Step>
    ### 将笔记切换至该配置方案 [#switch]

    ZotLit 会对所有匹配该条目的新建笔记使用此配置方案。若要切换已有笔记的配置方案，请打开该笔记，打开命令面板，并运行 <Command inline name={m.command_switch_literature_note_profile_name()} />。

    ![运行“切换文献笔记配置方案”后打开的配置方案列表，其中 Books 这一行及其笔记路径用红框标出](/img/how-to/use-different-templates-6-switch.webp)

    列表中会显示各个配置方案及其文件夹以及该笔记对应的路径。选择 **Books** 即可将该笔记应用此配置方案。已有笔记在手动切换之前，会始终保留创建它们时所用的配置方案。

  </Step>
</Steps>

## 当两个配置方案同时匹配时 [#overlap]

两个配置方案可能会同时匹配同一个条目，此时 ZotLit 不会自动为你做出选择。选择器会弹出并提示 <UiLabel name={m.modal_profile_problem_overlap({ profiles: "…" })} />。其搜索框提示为 <UiLabel name={m.modal_profile_overlap_placeholder()} />，且每个匹配该条目的候选配置方案都会带有 <UiLabel name={m.modal_profile_match_candidate()} /> 标识。

选择你打算使用的配置方案，或者关闭选择器取消创建笔记。在 <UiLabel name={m.workbench_tab_match()} /> 标签页中收窄条件是彻底解决此问题的方法。

## 手动选择配置方案时 [#manual]

无论条件如何设置，你在当前操作中手动选择的配置方案始终优先于配置方案匹配（Profile Match）。关于 ZotLit 选用配置方案时的匹配顺序，请参阅[配置方案](/docs/reference/templates/how-templates-work#profiles)。

你的手动选择仅作用于当前这一次操作。笔记会记录创建它时所用的配置方案，后续的更新会读取该记录而非重新根据条件判断。

## 将配置方案作为单个文件分享 [#share]

配置方案是一个单一文档，因此你可以将其作为独立文件迁移至另一个仓库，其中调用的片段也会一并打包在内。[配置方案文档](/docs/reference/templates/profile-document)参考文档中详细说明了该文件内的每一个键。

<Steps>
  <Step>
    ### 分享配置方案 [#share-profile]

    在该配置方案所在的行中，打开 <UiLabel name={m.workbench_more_actions()} /> 并选择 <UiLabel name={m.settings_profile_share()} />。

    ![Books 所在行的菜单，其中“分享”用红框标出](/img/how-to/use-different-templates-7-share-menu.webp)

    分享对话框会收集该文档及其调用的片段。

  </Step>
  <Step>
    ### 选择文件包含的内容 [#share-options]

    在 <UiLabel name={m.profile_share_partials()} /> 下，取消勾选任何不想导出的片段。<UiLabel name={m.profile_share_include_match()} /> 会将配置方案匹配（Profile Match）带到接收仓库，而 <UiLabel name={m.profile_share_folders()} /> 会添加你的笔记文件夹。选择 <UiLabel name={m.profile_share_copy()} /> 将文件复制到剪贴板，或选择 <UiLabel name={m.profile_share_save()} /> 将其写入你选择的文件夹。

    ![“分享 Books”对话框，其中“复制到剪贴板”用红框标出](/img/how-to/use-different-templates-8-share-dialog.webp)

    两者都会生成完全相同的单个文档。通知 <UiLabel name={m.profile_share_copied()} /> 会确认复制成功。

  </Step>
  <Step>
    ### 在接收仓库中导入 [#import]

    运行 <Command inline name={m.command_import_profile_name()} />，或者在 <UiLabel name={m.settings_profile_other_heading()} /> 列表的顶部标题中选择导入按钮。然后选择 <UiLabel name={m.profile_import_clipboard()} /> 或 <UiLabel name={m.profile_import_file()} />。

    ![导入配置方案列表，其中“从剪贴板读取”用红框标出](/img/how-to/use-different-templates-9-import-source.webp)

  </Step>
  <Step>
    ### 查看导入对话框显示的信息 [#import-dialog]

    对话框会显示配置方案、其文件夹与引文样式，以及作为筛选表达式传入的配置方案匹配。<UiLabel name={m.profile_import_include_match()} /> 会连同配置方案一起导入匹配规则，使其在当前仓库中也能自动选用；将其关闭则该配置方案仅供手动选择。选择 <UiLabel name={m.profile_import_confirm()} /> 即可写入该配置方案。

    ![导入配置方案对话框，文件夹与引文样式上方的“导入匹配条件”开关用红框标出](/img/how-to/use-different-templates-10-import-dialog.webp)

    <UiLabel name={m.profile_import_none_changed()} /> 当被分享的配置方案不包含匹配规则时，对话框会显示 <UiLabel name={m.profile_match_absent()} /> 并隐藏该开关。

  </Step>
</Steps>
