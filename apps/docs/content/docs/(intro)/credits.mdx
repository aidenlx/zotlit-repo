Names are listed alphabetically, not by amount of contribution.

## Inspirations

Projects that inspired ZotLit.

- [BibNotes Formatter](https://github.com/stefanopagliari/bibnotes)
- [obsidian-citation](https://github.com/hans/obsidian-citation-plugin)
- [obsidian-zotero-integration](https://github.com/mgmeyers/obsidian-zotero-integration)
- [zotero-plugin-scaffold](https://github.com/zotero-plugin-dev/zotero-plugin-scaffold): Zotero devtool hot-reload workflow
- [obsidian-pandoc-reference-list](https://github.com/mgmeyers/obsidian-pandoc-reference-list)
- [PDF++](https://github.com/RyotaUshio/obsidian-pdf-plus): PDF annotation
- [ZotFlow](https://github.com/duanxianpi/zotflow): Zotero PDF reader in Obsidian

## Tutorial authors

Community members who wrote tutorials for ZotLit v1 before the documentation existed.

- [@FeralFlora](https://github.com/FeralFlora): [ZotLit template walkthrough](https://forum.obsidian.md/t/zotlit-previously-obsidian-zotero-import-templates/56901) (Obsidian Forum)
- [@MichaTarlton](https://github.com/MichaTarlton): [Beginner's set up for AidenLX's Zotero Integration Plugin](https://gist.github.com/MichaTarlton/67c24bfe65bb4cc2c6158e67363a4b45) (Gist)

## Contributors

Contributors whose proposals shipped in v2. In most cases the original pull request was closed and the idea was reimplemented during the v2 rewrite.

- [Ascarshen](https://github.com/Ascarshen): Zotero 8 support and citation-key handling stabilization (merged into v1)
- [DanielRunningen](https://github.com/DanielRunningen): full-date parsing and bulk create/update of literature notes
- [OliverDudgeon](https://github.com/OliverDudgeon): related items and relations in templates
- [theotheo](https://github.com/theotheo): folder routing by allowing `/` in filenames to specify directories
- [Tisen-Ray](https://github.com/Tisen-Ray): Zotero 9 support
- [yukiizumi3](https://github.com/yukiizumi3): custom Zotero column showing each item's Obsidian note status
