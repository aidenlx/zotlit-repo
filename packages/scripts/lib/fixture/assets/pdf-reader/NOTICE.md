# PDF reader test PDFs

These files are generated by `generate.ts` in this directory. They contain no
third-party document content and use ZotLit's AGPL-3.0-or-later license. These
tests read them from this directory:

- the `@zotlit/pdf-reader` browser tests (`packages/pdf-reader/test/fixtures.ts`);
- the `@zotlit/annotations` text-structure Electron renderer test
  (`text-structure.test.ts` and `text-structure.browser-test.ts`), which reads
  `mock-form.pdf` and `mock-direct.pdf`.

The Fixture build copies them into the Fixture Vault:

- the files in `PDF_READER_PDFS` (`../../spec.ts`) go to
  `attachments/pdf-reader/` for the `pdf-reader.md` page and the End-to-end Run;
- the files in `SELECTION_LINK_PDFS` (`../../spec.ts`), `mock-form.pdf` among
  them, go to `attachments/selection-links/` for the
  `pdf-reader-selection-links.md` page;
- `mock-form.pdf` is also the source of the Attachment `FRMXPDF2`, "Form
  XObject PDF", at `attachments/form-xobject.pdf`, which Paired Run case E-1
  reads;
- `theme.pdf` has a copy in `vault-pages/`.

- `mock-form.pdf` — the repro of
  [#2033](https://github.com/aidenlx/zotlit/issues/2033). One page that copies
  the structure of an affected CNKI (`ReaderEx_DIS`) page: crop box
  `[8.5 8.5 603.78 816.38]`, every text run inside one Form XObject `/Xf131`,
  each run drawn with a flipped millimetre `cm`, and a DOI stamp drawn directly
  on the page. The text is placeholder in the non-embedded fonts
  `STSong-Light` (`UniGB-UCS2-H`) and `Times-Roman`. SHA-256:
  `6e2a867dc0c2133c1353706bb7fa187113c27dfaa206a443dc893fcff4b9e027`.
- `mock-direct.pdf` — the control: the same runs at the same positions, drawn
  directly on the page with no Form XObject. SHA-256:
  `9cd1eb54b00921314f658bbe99c3bdb33b97cea68ea241e64869daba48ec3621`.
- `jbig2.pdf` — one 200 × 200 pt page whose only content is a 64 × 64
  `JBIG2Decode` image: a black 32 × 32 square on white, coded as one MMR
  generic region. SHA-256:
  `83df23a5588625ca2b10a1b8733628d4b4e8e6ab50d5439bf2fab38f07e29716`.
- `jpx.pdf` — one 200 × 200 pt page whose only content is a 64 × 64
  `JPXDecode` image: an 8-bit grey JPEG 2000 codestream with one empty packet,
  so every sample decodes to 128. SHA-256:
  `a9d6622251d032e0c4776e757aa592255ec0d86bfc56935b67ff1fd8a79ba95b`.
- `navigation.pdf` — eight Letter pages of numbered Helvetica lines, for the
  reader's navigation tests: the named destinations `chapter-three` (page 3)
  and `chapter-six` (page 6) in the catalog `/Dests`, and one Text annotation
  (id `5R`) on page 4. SHA-256:
  `ef5603e4dac97dbe1df7d93d7dd3706512ff9563fec87b90b5a552afb14516f2`.
- `standard-fonts.pdf` — one Letter page with one line in each of the 14
  standard Type 1 fonts, none embedded (Times, Helvetica and Courier in four
  styles each, Symbol and ZapfDingbats), for the reader's standard font tests.
  SHA-256:
  `e5e757277b371bb98c7f871691c3da1760a2461932bd59a4a95fda681a0e04a1`.
- `chrome.pdf` — three Letter pages of Helvetica lines (WinAnsi, so the
  first line has the accented words "Café résumé naïve"), for the reader
  chrome tests: page labels `i`, `1`, `2`; an outline of Introduction (XYZ),
  Methods (XYZ, with the closed child Sampling, FitH) and Project site (a URI);
  a Highlight annotation (id `9R`, author Ada Lovelace, contents "Check this
  sentence.") over the second line of page 2; a URI link (id `10R`) and a link
  to page 3 (id `11R`) on page 1. SHA-256:
  `0194a9425b3a4f9431dd6b65bafa39684117fad5345f1486246c2a8dcc3ebbd2`.
- `password.pdf` — one empty 200 × 200 pt page under the Standard security
  handler (RC4, 40-bit, revision 2) with the user password `zotlit` and the
  owner password `zotlit-owner`. SHA-256:
  `4da42e475875b862b734e284d3b4adc6c25772bab6b071612fc94075979916a9`.
- `mixed-sizes.pdf` — two empty pages, one Letter portrait (612 × 792 pt) and
  one Letter landscape (792 × 612 pt), for the thumbnail aspect test. SHA-256:
  `534a286164719652769cd3583fdc487d502e265c001a35824f73d7a941470f4d`.
- `forms.pdf` — one Letter page of Helvetica lines with the plain-text URL

  `e3c2094f0358941591785c3856846880c56cf179e65d9c71e3db0bf44899cf4f`.
- `theme.pdf` — one 300 × 200 pt page for the Adapt to theme test: a dark

  `daeb28d5b60ebb6688f8ad68d1ba60725d95875008744e861a924b586a49e02d`. The
  generator also writes it to `../../vault-pages/pdf-reader-theme.pdf` for the
  Fixture Vault page `pdf-reader-theme.md`.

The two mocks are byte-identical to the files attached to #2033, which the
issue's `mkmock.py` (pikepdf) wrote. Regenerate all eleven from the repository
root:

```sh
node packages/scripts/lib/fixture/assets/pdf-reader/generate.ts
```
